# Como publicar tu perfil de GitHub

1. En GitHub, crea un repositorio publico llamado exactamente `JorgeLT1`.
2. Sube el archivo `README.md` de esta carpeta a la raiz de ese repositorio.
3. Sube tambien la carpeta `.github/workflows/snake.yml` para activar la animacion de contribuciones.
4. En GitHub, abre la pestana `Actions` y acepta habilitar workflows si GitHub lo pide.
5. Ejecuta manualmente el workflow `Generate contribution snake` una vez para que aparezca la serpiente.

## Ajustes rapidos

- Cambia el enlace de LinkedIn en `README.md`, donde dice `href="#"`.
- Cambia el enlace de Portafolio en `README.md`, donde dice `href="#"`.
- Si quieres otro estilo visual, cambia `tokyonight` por temas como `radical`, `dracula`, `github_dark` o `transparent`.
- Si tu usuario de GitHub cambia, reemplaza todas las apariciones de `JorgeLT1`.
